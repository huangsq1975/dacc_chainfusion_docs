另列、不計入基準的項目

  • Aegis 返工預備：+10–20 PD，因為 API 還沒實作。觸發條件：A 階段過半時 Aegis dev 環境仍不可用。
  • 自然人投資人：+6–10 PD。
  • 若 DigiQuick 只提供系統給安排行使用、不自己擔任簿記管理人：訂單簿的權限模型 ±3–5 PD。

估算假設

  • 首發投資人是法人，沿用現有「公司＋聯絡人」註冊，投資人不選資產類型。
  • DigiQuick 是發行營運中樞：不持有私鑰、不執行鏈上交易、不處理資金。鏈上動作都以結構化業務意圖交給 Aegis 執行。
  • 簿記在系統內：投資人可在 APP 下單，OPS 也可在 admin 代下單；分配在系統內完成，並做雙人核准。
  • 付款一律人工；DigiQuick 只負責交割編排：發出交割指示、記錄並覆核到帳憑證，確認後才送出 mint 意圖。
  • DigiQuick 的登記冊是權威，Aegis 和鏈上是鏡像（前提是法律上允許 DigiQuick 擔任登記處）。
  • DigiQuick 計算固定利率的應得金額，付款代理執行付款。浮動利率和提前贖回放在 C。
  • 不開放外部地址（要等 Aegis 主網 KYT）。
首發日期取決於 Aegis 三個環境的交付日期和律師文件定稿，不取決於 DigiQuick 的開發。
